Food Delivery System

A comprehensive food delivery application designed and built specifically to practice and demonstrate core Object-Oriented Programming (OOP) principles, software design patterns, and clean code architecture.

## 🎯 Project Objective

The primary goal of this project is not to build a commercial product, but to model a real-world system using object-oriented design. It focuses heavily on structuring relationships between entities (Users, Orders, Payments).

## ⭐ App Features
### 👤 Customer
* Browse restaurants and view menus.
* Add, remove, and modify items in a shopping cart.
* Place orders and calculate total costs (including tax and delivery fees).
* Track order status (Pending -> Preparing -> Out for Delivery -> Delivered).


### 🚗 Delivery Driver
* View available delivery requests.
* Accept deliveries and update status to "Delivered".

## 💻 Tech Stack

* **Language:** Java
